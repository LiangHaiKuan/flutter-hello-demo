## 2. 核心功能明细

### 2.1 扫描页（MainActivity）
- Tab1「可用设备」：设备卡片 = 蓝牙图标、名称、MAC、配对状态（未配对/已配对）、可连接性、RSSI（dBm）、连接按钮
- Tab2「活动连接」：已连接设备列表，可多设备同时连接，点击进入设备详情
- 侧滑抽屉「扫描过滤」（截图 10-13-04）：
  - 按名称/地址关键字过滤
  - 0x 按 UUID 过滤
  - 只显示 BLE 设备（默认勾选）
  - 只显示已收藏
  - 只显示名称不为空
  - RSSI 阈值滑条（-100 ~ 0）
- 扫描设置：搜索周期、循环搜索（官方功能清单第 2 条）
- 收藏设备（收藏后可在过滤里只看收藏）
- 扫码连接（ScanQrCodeActivity）
- 广播数据页（点设备进入或长按）：RSSI 折线图（随时间）、原始广播数据 hex、AD 结构解析表（LEN/TYPE/VALUE）、复制原始数据
- 右上角菜单：分享 app 链接（跳过）、扫描过滤、设置等

### 2.2 设备详情页（DeviceActivity）
- Tab1「蓝牙服务」：GATT 服务树，可展开
  - 服务：名称（通用 Access / Unknown Service / Nordic UART 等，已知 UUID 显示友好名）+ UUID
  - 特征值：UUID、Properties（READ/WRITE/WRITE_NO_RESPONSE/NOTIFY/INDICATE…）、图标
    - 写类型特征 → 上传图标，点击弹出写入面板
    - NOTIFY/INDICATE 特征 → 铃铛图标，点击开关通知（记住每个特征最后状态，LastNotifyCharacteristic 表）
  - 点特征值可读/写，写支持 hex / ascii 两种格式
- Tab2「实时日志」（截图 10-09-18）：
  - 关键字过滤（不区分大小写）
  - 格式下拉：hex / ascii
  - 按钮：自动滚动、显示发送、固化（把当前过滤+格式设为默认）
  - 收发统计：收 N包/字节，发 成功/失败 包数/字节
  - 日志行：时间戳 + [服务UUID缩写] 方向（Notify / 发送 / 读），hex 绿色显示，收/发颜色区分
  - 全屏按钮 → 横屏全屏日志
- 底部发送栏（截图 10-08-21）：
  - 输入框，提示「数据格式：aa00bb11cc22（支持空格）」
  - 发送按钮 + 下拉展开高级面板
  - 高级面板：历史记录（时钟图标，WriteHistory 表）、自定义按键面板（宏）、格式选择 hex/ascii、写入类型（Default / No Response / Signed）、循环发送 + 延迟(ms)
  - 长按发送框可从历史/自定义按键填入

### 2.3 自定义按键（FastSendCmdActivity，截图 10-12-*）
- 命令卡片：勾选框、格式标签（hex）、名称、数据预览、发送按钮
- 操作提示：单击修改；长按将数据填入发送输入框
- 添加 / 排序（拖拽排序）；编辑模式底部栏：全不选 / 删除 / 发送 / 导出命令
- 导出格式（与用户 fast_cmds txt 一致）：`序号,名称,编码格式(hex|us-ascii),数据`，数据为空格分隔 hex 字节
- 导入同格式文件
- 数据库表 FastSendCmd 持久化

### 2.4 外围模式（PeripheralModeActivity）❓
- 手机模拟 BLE 从机：自定义广播内容、广播间隔、可写/可通知特征，等待中央连接并收发数据

### 2.5 DFU 固件升级（DfuActivity）❓
- 原版带 PixelBleDfuService（Nordic DFU 风格 OTA）
- 需要确认用户设备是否用得上

### 2.6 发送文件（SendFileActivity）
- 选择本地文件按特征值分片发送（含分包大小/间隔设置）

### 2.7 日志管理（LogMgrActivity + DailyLogsActivity）
- 实时日志落盘（Room Logs 表），按天查看、导出 txt

### 2.8 通知转发（PixelBleNotificationActivity）❓
- 手机通知/来电/短信转发到已连接蓝牙设备（官方"通知同步"）

### 2.9 设置页（SettingsActivity）
- 主题颜色切换（原版有多主题 Dialog）、扫描周期设置、日志设置、精简版界面开关、隐私政策、关于/版本

## 3. 技术选型（Flutter）

| 项 | 选择 | 理由 |
|---|---|---|
| BLE | flutter_blue_plus | 社区主力、活跃维护、支持 Android 12+ 权限、MTU/连接参数 |
| 权限 | permission_handler | BLUETOOTH_SCAN/CONNECT/ADVERTISE + 定位 |
| 图表 | fl_chart | RSSI 折线图 |
| 扫码 | mobile_scanner | 二维码连接 |
| 存储 | shared_preferences + sqflite（或 drift） | 收藏/命令/历史/日志 |
| DFU | nordic dfu 包（nordic_dfu / flutter_nordic_dfu） | 若需要 |
| 状态管理 | 原生 setState/ValueNotifier 起步 | 小团队省事，不引入额外复杂度 |
| 编译 | 沿用现有 GitHub Actions（build-apk.yml） | 云编译闭环不变 |

UI 风格：橙色主色调 + 浅灰背景 + 白色圆角卡片，对标截图版式（顶部橙色 AppBar、底部橙色发送栏）。

## 4. 权限清单（对标原版，去掉广告相关）
- BLUETOOTH_SCAN / BLUETOOTH_CONNECT / BLUETOOTH_ADVERTISE（外围模式）
- ACCESS_FINE_LOCATION（Android 11 及以下扫描需要）
- CAMERA（扫码）
- 前台服务（后台保活连接，可选）

## 5. 里程碑
1. **M1 骨架**：工程重建 + 主题 + 扫描页（列表/过滤/RSSI）+ 权限
2. **M2 连接**：连接管理（多设备）+ 服务树 + 特征值读写/通知
3. **M3 收发**：发送栏（hex/ascii、写入类型、循环发送、延时）+ 实时日志（过滤/统计/全屏）+ 历史
4. **M4 效率**：自定义按键（增删改排序导入导出，兼容 fast_cmds 格式）+ 收藏 + 扫码连接
5. **M5 进阶**：广播数据页（图表+AD 解析）、发送文件、日志管理导出、外围模式（若确认）、DFU（若确认）
